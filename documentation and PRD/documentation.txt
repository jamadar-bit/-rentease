📘 Product Requirements Document (PRD)
Project: RentEase – Furniture & Appliance Rental Platform
Overview
RentEase is a modern, web-based rental platform that allows students and professionals to rent furniture and home appliances easily on a monthly basis. It provides flexibility, convenience, and affordability while promoting sustainable consumption.

🎯 Problem Statement
People relocating frequently for work or education find it impractical to buy furniture and appliances due to:

High upfront purchase costs
Difficulties during relocation
Lack of flexible rental terms
Poor maintenance and limited local options
RentEase addresses these issues by offering an accessible rental platform with end-to-end management—from selection to delivery and return.

🧩 Objectives
Primary Objectives
Enable users to rent furniture and appliances easily online.
Provide flexible tenure, delivery, and maintenance services.
Manage inventory, pricing, and logistics from an admin dashboard.
Secondary Objectives
Reduce material waste and encourage sustainability.
Support local suppliers/vendors with an online marketplace.
Improve relocation convenience.
📦 Scope of Work
In-Scope
Responsive web application (React + Vite + Tailwind).
RESTful backend using Node.js + Express.
MongoDB for product, user, and transaction data.
Admin panel for managing products, users, rentals, and orders.
Out of Scope
Native mobile apps
AI-based pricing or recommendation systems
Cross-border rentals
Resale of second-hand products
🧠 Functional Requirements
User Features
User registration and login (JWT authentication)
Browse products by category (Furniture, Appliances)
Detailed product view (price, deposit, availability, tenure)
Add to cart & checkout
Choose delivery/pickup dates
Manage active rentals
Submit maintenance requests
View rental history and invoices
Admin / Vendor Features
Admin authentication and dashboard
Add/edit/delete product listings
Manage rental prices and tenure options
Control inventory availability
Handle delivery and pickup requests
Respond to maintenance tickets
Manage user accounts
Track orders, damages, and disputes
Generate analytics and business reports

🧰 Development & Setup Documentation
1. Project Initialization
Frontend:

bash


npm create vite@latest rentease --template react
cd rentease
npm install tailwindcss @tailwindcss/vite
Edit vite.config.ts

ts


import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'
export default defineConfig({
  plugins: [tailwindcss()],
})
Style setup src/index.css

css


@import "tailwindcss";
Backend setup:

bash


mkdir backend
cd backend
npm init -y
npm install express mongoose cors dotenv bcrypt jsonwebtoken

POST	/api/rentals	Create rental
GET	/api/rentals/:id	Get user rentals
PUT	/api/rentals/return/:id	Return rental
POST	/api/admin/products	Add product
GET	/api/admin/dashboard	Admin stats
